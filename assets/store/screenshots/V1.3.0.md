# v1.3.0 screenshots

Use these current images for the 1.3.0 store update. Do not reuse the historical `01`–`05` images that show removed inline response controls.

- `v1.3.0-player-active.jpg`: real ChatGPT session in Windows Edge, native Read Aloud response button and separate capsules, captured 26 October 2026.
- `v1.3.0-player-paused.jpg`: same live session after pausing, with position and duration retained. Resume and seeking were also observed during capture.
- `v1.3.0-dashboard.png`: actual unpacked 1.3.0 settings page rendered in the browser verification profile; this is an extension-page capture, not a live ChatGPT screenshot.

All three images are 1280×800. Player images are cropped to omit account navigation, use a new neutral temporary conversation, and contain no simulated UI. The browser viewport was temporarily adjusted for capture and restored afterward. The page's existing 90% zoom remained in effect; this is not evidence of the full zoom acceptance matrix.

The captures use the build containing the direct-URL retention fix (`3c3a6e2`). README and website now use the current player/dashboard images. Uploading them in the store consoles remains a separate publisher step.
