# ChatGPT Audio Controls

1. Use the browser profile the user requested. Check its Extensions menu for **ChatGPT Audio Controls** first. If absent, open the official [Chrome listing](https://chromewebstore.google.com/detail/aifalimlfgiepmbejcemcofninobaiea/) or [Edge listing](https://microsoftedge.microsoft.com/addons/detail/cmhbacgmcgiolpidfjcpefkhbbeamemf). Verify the item ID against the link and use the store's install action. Hand the browser confirmation to the user if your controls cannot accept it. Verify installation in the Extensions menu.
2. Refresh the intended chatgpt.com tab after installation. Use the requested conversation, or a fictional prompt for a test. On a completed assistant response, activate **Read aloud** in the response actions or its overflow menu. The audio and voice come from ChatGPT. If sign-in is required, let the user sign in.
3. Expand the player by selecting its small logo. If it is missing, open the extension popup and check **Hide floating controls**, then return to the chat. Confirm the timestamp advances. Pause, verify it stops, and resume. Use the backward/forward controls or scrub the seekbar, then open the speed selector and verify the displayed speed. Compact layouts place secondary controls under **More**.
4. To save audio when requested, wait for the full download to become available. Select **Download** in the player or the download-ready notification. Verify the saved file in browser downloads. A paused or ended stream alone does not establish download readiness. If capture is unavailable, report that state rather than repeatedly triggering Read Aloud.

Use the [installation guide](https://chatgpt-audio-controls.infoxica.com/installation/) and [player guide](https://chatgpt-audio-controls.infoxica.com/guide/) for the active release.
