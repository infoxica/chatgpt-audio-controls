# ChatGPT Audio Controls 1.3.0

This update restores playback controls after recent ChatGPT changes. Start listening with ChatGPT’s own Read Aloud button beside a response.

- **Pause and resume reliably.** Keep your place, playback speed, and volume when resuming after a pause.
- **Player controls that fit.** Two separate rounded capsules sit beside the message box when space permits, or above it on smaller screens.
- **One Read Aloud button.** The extension no longer adds a duplicate response button.
- **Choose your appearance.** Popup, dashboard, and feedback support System, Light, and Dark preferences.
- **Help and feedback are easier to find.** Help sits beside Dashboard in the popup. Send feedback from About or settings, in any of the 17 supported languages.

The standalone Tampermonkey userscript includes the playback and capsule fixes. Popup and dashboard features apply to the browser extension.

After updating, refresh your ChatGPT tabs. Start a new Read Aloud session using ChatGPT’s native button, then use the player to pause, resume, seek, change speed, adjust volume, or download audio.

Feedback is optional and private. [Tell us what could work better](https://chatgpt-audio-controls.infoxica.com/feedback?source=installed&version=1.3.0).

Chrome and Edge review updates separately. Check the installed extension version in your browser; a published GitHub release does not establish availability in either store.
